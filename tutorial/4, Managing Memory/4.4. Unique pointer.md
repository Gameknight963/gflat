# Unique pointer

`Standard::Memory::Unique<T>` is a type which aims to automate some of the process named in section 4.3. It defines a destructor to automatically free memory once it goes out of scope.

It is still a work-in-progress.

```cpp
using Standard::Memory;

int main()
{
    void*? allocation = Memory::Allocate((nuint)sizeof(int));
    if (allocation == null) return 1;
    int* ptr = (int*)allocation;
    *ptr = 48;
    Unique<int> unique = new(ptr);
    Console::WriteLine(unique.Value);
    // The allocation is freed automatically before the function returns
    return 0;
}
```

```cpp
Unique<T> unique = new(ptr);
```

Creates a `Unique<T>` which takes responsibility of freeing `ptr`. **Do not free `ptr` manually past this point**.

```cpp
unique.Value
```

Gets the value (48) stored within the pointer.
