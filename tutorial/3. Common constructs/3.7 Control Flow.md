# Control Flow

### `if`

This allows you to branch your code depending on whether a boolean is true:

```cpp
int main()
{
    bool condition = true;
    if (condition)
    {
        // this will run
        Console::WriteLine("was true!");
    }
    else
    {
        // this won't
        Console::WriteLine("was false.");
    }
    return 0;
}
```

You can use _embedded statements_ to make single-line cases like these look nicer. They let you skip the braces if there's only one statement in the block:

Filename: if_statements.gf

```cpp
int main()
{
    int x = 5;
    if (x > 5)
        Console::WriteLine("was true!");
    else
        Console::WriteLine("was false.");
    return 0;
}
```

Try running this code; you should see the following output:


```
$ gfc if_statements.gf --run
was false.
```

Let’s try changing the value of `x` to a value that makes the condition true:

```c
    int x = 7;
```

```
$ gfc if_statements.gf --run
was true!
```

#### The ternary operator

The ternary operator is similar to if-else, but it's an expression instead. To write a ternary syntax, place a condition first, follow it with a question mark (`?`) and the value to use if the condition is true, and then add a colon (`:`) followed by the value to use if the condition is false:

Filename: if_statements.gf

```cpp
int main()
{
    int x = 7;
    Console::WriteLine(x > 5 ? "was true!" : "was false.");
    return 0;
}
```

```
$ gfc if_statements.gf --run
was true!
```

Remember that since the ternary is an expression, the type must be known at compile time. Thus, we cannot use unrelated types in the ternary:

```cpp
int main()
{
    int x = 7;
    Console::WriteLine(x > 5 ? 492 : "was false"); // error, expected int
}
```

## Loops

There are four types of loops in G♭. Let's start with the most familiar one first:

## The `for` loop

Fileame: loops.gf

```cpp
int main()
{
    for (int i = 0; i < 5; i++)
    {
        Console::WriteLine(i);
    }
    return 0;
}
```

```
$ gfc loops.gf --run
0
1
2
3
4
```

What's happening here?

A `for` loop always follows this structure:

```c
for (<initialization>; <condition>; <increment>)
{
    // code to repeat
}
```

- Initialization: Sets up a starting counter. It can technically be a variable declaration or an expression, but that's what you're meant to use it for.
- Condition: Any boolean expression that is checked before each run. If it evaluates to false, the loop stops. You should use it to check your counter.
- Increment: Updates the counter after each run (e.g., i++). (Again, it can technically be any expression).

So, after the fifth run, `i` is now 5. Since 5 is not less than 5, the condition `5 < 5` evaulates to false, ending the loop.

If you don't provide a condition, the loop just simply runs forever, which allows you to do this:

Filename: loops.gf

```cpp
int main()
{
    for (;;)
    {
        Console::Write("a");
    }
}
```

If your terminal doesn't support Ctrl+C, god help you.

```
$ gfc loops.gf --run
aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa^C
```

Why does this even compile? We forgot `return 0;`!

Well, we don't actually need it here. The compiler knows this for loop will run forever, and that any code beyond it is unreachable. Putting `return 0;` in this case might actually result in an "Unreachable code detected" warning!

## The `while` loop

A while loop is much simpler. It follows this structure:

```c
while (<condition>)
{
    // code to repeat
}
```

The code runs while that condition is true. It checks _before_ running the block inside each time. We can use it to do what a `for` loop does for us manually:

Filename: loops.gf

```cpp
int main()
{
    int i = 0;

    while (i < 5)
    {
        Console::WriteLine(i);
        i++;
    }

    return 0;
}
```

```
$ gfc loops.gf --run
0
1
2
3
4
```

## `foreach` (the best loop)

`foreach` is the BEST loop (in my opinion).

It's a bit difficult to discuss without using more advanced features such as collections, generics, and objects, so don't worry if you're confused.

Essentially: a `foreach` loop lets you interate over the items of a collection.

Filename: loops.gf
```cpp
using Standard::Collections;

int main()
{
    Vector<int> vector = new();
    vector.Add(5);
    vector.Add(6);
    vector.Add(34);
    vector.Add(-3);

    foreach(int item in vector)
    {
        Console::WriteLine(item);
    }
    return 0;
}
```

```
$ gfc loops.gf --run
5
6
34
-3
```

In plain english, this code:
- creates a collection of integers
- adds 5, 6, 34, and -3 to it
- Loops over each item in the collection and prints it
