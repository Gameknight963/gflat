# Statements and Expressions

A function may _return_ a value, which means that the caller may use it as an expression.

Filename: expressions.gf

```cpp
int main()
{
    Console::WriteLine(CoolFunction(5););
    return 0;
}

int CoolFunction(int x)
{
    Console::WriteLine(x);
    return x + 1;
}
```

```
$ gflat expressions.gf --run
5
6
```

An expression is any code that evaluates to a value. The type of an expression must always known at compile time.

Since `CoolFunction()` returns a value, we may use it as as an expression, passing it directly to `WriteLine()`.

We can also use it as a statement, ignoring the return value:


Filename: expressions.gf

```cpp
int main()
{
    CoolFunction(5);
    return 0;
}

int CoolFunction(int x)
{
    Console::WriteLine(x);
    return x + 1;
}
```

```
$ gflat expressions.gf --run
5
```

Returning values is useful, but sometimes we want a function which doesn't return anything.

What if CoolFunction didn't return a value? We can do that by declaring it's return type as `void`:

```cpp
void CoolFunction(int x)
{
    return x + 1; // Compile error!
}
```

Returning a value is not allowed in a `void` function!

You can use `return` without a value though, which will prevent further code in that function from executing:

```cpp
void CoolFunction(int x)
{
    return;
    Console::WriteLine("This will never print.");
}
```

Any function that returns `void` may not be used as an expression, only as a statement:

```cpp
int main()
{
    CoolFunction(5); // This will work
    Console::WriteLine(CoolFunction(5)); // Compile error!
    return 0;
}

void CoolFunction(int x)
{
    return;
    Console::WriteLine("This will never print.");
}
```
