## Comments

Most programming languages are pretty readable. Unfortunately, we're using G♭, so we'll need a way to make our programs more readable. 

In all seriousness, sometimes something _does_ require more explanation. In this case you might want to leave a _comment_ in your code. The compiler ignores these, but people reading your code might find them useful.

Here's a simple comment:

```c
// hello!
```

In G♭, comments begin with `//` and extend until the end of that line.

If you want a comment that spans multiple lines, you can use a _block comment_:

```c
/*
We're doing something complicated here!
Hopefully this comment will be long enough
to explain what we're doing.
*/
```

You can also just use multiple single-line comments:

```c
// We're doing something complicated,
// but not quite so complicated that we need
// a bock comment to explain it.
```

Comments can also be placed at the end of lines containing code:

```c
int main() {
    int luckyNumber = 777; // I'm feeling lucky today!
    return 0;
}
``` 

More commonly though, they're placed on top of the line they annotate:

```c
int main() {
    // I'm feeling lucky today!
    int luckyNumber = 777;
    return 0;
}
```
