# SHA-512 byte digests

`Standard::Hashing::SHA512` incrementally hashes counted bytes with independently copied
inline state. Explicit source selection needs `core/Hashing/SHA512.gf` and
`core/Numerics/BitOperations.gf`. No allocator, String, GC, or exception definitions
are needed. The algorithm follows [RFC 6234 sections 4-6](https://www.rfc-editor.org/rfc/rfc6234.html).

```csharp
using Standard; using Standard::Hashing;

int main()
{
    SHA512 hash = new();
    if (!hash.TryAppend("abc", 3)) return 1;
    byte[64] digest = hash.GetHash();
    if (digest[0] != (byte)0xdd || digest[63] != (byte)0x9f) return 2;
    return 0;
}
```

Construction and `Reset()` start an empty message. `TryAppend(data, count)` reads
exactly the selected bytes, including NUL and high bytes. Input chunk boundaries
do not affect the digest. No input pointer is retained, so consumed input storage
can be reused. A zero count succeeds without reading the pointer.

`GetHash()` is an immutable operation returning an independent fixed `byte[64]`
value in SHA-512's defined big-endian word order. It pads and finalizes a snapshot:
repeated calls agree, and later appends continue the original message. Copying the
hasher copies the complete running state, including pending input. Copies can
continue with different suffixes. The result needs no disposal operation.

The largest accepted total is `2^125 - 1` bytes, satisfying SHA-512's limit of
fewer than `2^128` bits. Two 64-bit counters track the complete byte count. An
append exceeding the limit returns false before reading input or changing state.
Every accepted nonzero count requires readable live input for its full extent,
unchanged during the call and disjoint from the mutable hasher state. Concurrent
mutation or mutation through other aliases is unsupported.

All operations are `nothrow` and use no internal heap allocation. State holds
eight 64-bit words and a pending 128-byte block. Compression uses an 80-word
stack schedule. There is no platform crypto dependency or hidden input ownership.
The API returns the complete digest. Use existing Hex routines when text is needed.
It does not provide keyed authentication or promise to erase intermediate state.

Tests compare binary inputs, padding boundaries, and incremental chunks with .NET
SHA512 and standard vectors. Counter-limit tests seed synthetic private counters
in a test-only access fixture.
The shared freestanding utility test is configured to check a dynamic-input
vector at O0 and O2 without default native libraries on Windows/Linux x64.
