# Unique pointer

`Standard::Memory::Unique<T>` is a type which aims to automate some of the process named in section 4.3. It defines a destructor to automatically destroy and free its object once it goes out of scope.

It is still a work-in-progress.

```cpp
using Standard::Memory;

int main()
{
    Unique<int> unique = new(new* int(48));
    Console::WriteLine(unique.Value);
    // The allocation is freed automatically before the function returns
    return 0;
}
```

```cpp
Unique<T> unique = new(ptr);
```

Creates a `Unique<T>` which takes ownership of `ptr`. The first example supplies a freshly constructed `int` directly. **Do not free `ptr` manually past this point**.

```cpp
unique.Value
```

Gets the value (48) stored within the pointer.
