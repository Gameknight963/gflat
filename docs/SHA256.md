# SHA-256 byte digests

`Standard::Hashing::SHA256` hashes a message incrementally:

```csharp
using Standard;
using Standard::Hashing;

int main()
{
    SHA256 hash = new();
    if (!hash.TryAppend("abc", 3)) return 1;
    byte[32] digest = hash.GetHash();
    if (digest[0] != (byte)0xba || digest[31] != (byte)0xad) return 2;
    return 0;
}
```

## State and snapshots

| Operation | Effect |
| --- | --- |
| Construction, `Reset()` | Starts an empty message |
| `TryAppend(data, count)` | Adds message bytes |
| `GetHash()` | Returns a `byte[32]` digest of the current message |

`GetHash()` finalizes a snapshot. Repeated calls agree, and later appends continue
the original message. Hasher copies can continue with independent suffixes.

Messages can contain at most `2^61 - 1` bytes. An append exceeding that limit
returns false and preserves state. Keep append input separate from the running
hasher state.

Digest words are serialized big endian as specified by
[RFC 6234](https://www.rfc-editor.org/rfc/rfc6234/). Use Hex to display the result,
[FileHash](FILE_HASH.md) for files, or [HMACSHA256](HMAC_SHA256.md) for keyed
authentication.
