# Hello, projects!

The G♭ project system is essential for making sure others can build your projects easily. In this section, we'll discuss the project commands and format.

Start by creating a new project. This creates a new folder with the name you seleced:

```
$ gflat new MyApp
$ cd MyApp
```

Inside this folder, you should now have a file named `MyApp.gfproj`.

Filename: MyApp.gfproj
```xml
<Project Sdk="Gflat.Sdk">
  <PropertyGroup>
    <OutputType>Executable</OutputType>
  </PropertyGroup>
</Project>
```

It is an MSBuild format project. The Visual Studio templetes produce a similar structure.

You can change the OutputType to these types:

 - Executable
 - SourceLibrary
 - StaticLibrary
 - DynamicLibrary

 For now, we'll only use Executable.
