# Functions

Functions are a part of basically every language (and even the cornerstone of some!).

You've already seen and declared a function: the `main` function!

By convention, G♭ uses PascalCase as the style for function names, in which the first letter of every word is capitalized, with no spaces or punctuation between them. The exception to this rule is the `main()` function.

Here is an example of declaring and calling a function:

Filename: functions.gf

```cpp
int main()
{
    Console::WriteLine("wow!");
    CoolFunction();
    return 0;
}

void CoolFunction()
{
    Console::WriteLine("cool!");
}
```

We declare a function in G♭ by entering the return type followed by a function name and a set of parentheses. 'void' is a special return type that indicates that the function does not return a value.

We can call any function we’ve defined by entering its name followed by a set of parentheses. Note that we defined `CoolFunction` _after_ the `main` function in the source code. G♭ doesn't care about the order; we could've just as easily declared `CoolFunction` first.

Run this program:

```
$ gflat functions.gf --run
wow!
cool!
```

## Parameters

You can also create functions that take parameters, similar to `WriteLine`:

Filename: functions.gf
```cpp
int main()
{
    Console::WriteLine("wow!");
    CoolFunction(5);
    return 0;
}

void CoolFunction(int x)
{
    Console::WriteLine(x);
}
```

Try running this program. You should get the following output:

```
$ gflat functions.gf --run
wow!
5
```

The declaration of `CoolFunction` has one `int` parameter named `x`. This means we can pass any `int` to `CoolFunction`, and it will print it to the console.

When defining multiple parameters, separate the parameter declarations with commas, like this:

Filename: functions.gf
```cpp
int main()
{
    Console::WriteLine("wow!");
    CoolFunction(5, 592);
    return 0;
}

void CoolFunction(int x, int y)
{
    Console::WriteLine(x);
    Console::WriteLine(y);
}
```

```
$ gflat functions.gf --run
wow!
5
592
```
