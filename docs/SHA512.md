# SHA-512 byte digests

`Standard::Hashing::SHA512` follows the same incremental API as [SHA256](SHA256.md)
and returns a `byte[64]` digest:

```csharp
using Standard;
using Standard::Hashing;

int main()
{
    SHA512 hash = new();
    if (!hash.TryAppend("abc", 3)) return 1;
    byte[64] digest = hash.GetHash();
    if (digest[0] != (byte)0xdd || digest[63] != (byte)0x9f) return 2;
    return 0;
}
```

`TryAppend(data, count)` adds bytes to the message. `GetHash()` finalizes a
snapshot, so repeated calls agree and later appends continue the original
message. `Reset()` starts an empty message. Hasher copies can continue with
independent suffixes.

The total message limit is `2^125 - 1` bytes. An append exceeding that limit
returns false and preserves state. Keep append input separate from running state.

Digest words use the big-endian serialization specified by
[RFC 6234](https://www.rfc-editor.org/rfc/rfc6234.html). For files, use
[FileHash](FILE_HASH.md). For keyed authentication, use
[HMACSHA512](HMAC_SHA512.md).
